# 简历工作台

一个 Vue3 + JavaScript 的 Web 端简历管理项目，支持简历新增、编辑、删除、本地保存、PDF 导出和 Word 导出。

## 功能

- 多份简历管理
- 基础信息、技能、工作经历、项目经历、教育经历编辑
- 浏览器 `localStorage` 自动保存
- 当前简历导出为 PDF
- 当前简历导出为 Word 可打开的 `.doc` 文件
- Vue Router 管理页面与简历详情地址
- Pinia 管理简历数据与编辑动作

## 运行

```bash
npm install
npm run dev
```
